# Standoffish

U.S. design studio site — website design & software product design.

- Domain: `www.standoffish.net` (`CNAME`)
- Stack: static HTML / CSS / JS (no build step)
- Language: **English only**

## Preview

```bash
cd ~/Documents/Personal-Engineering/projects/standoffish
python3 -m http.server 8080
# http://localhost:8080
```

## Deploy

GitHub Pages or any static host. Push `main`.

## Customize

| File / area | What to change |
|-------------|----------------|
| Case studies in `index.html` | Real client names & copy |
| `hello@standoffish.net` | Your business email |
| Hero stats | Real numbers |
| `assets/images/` | Real project screenshots |
